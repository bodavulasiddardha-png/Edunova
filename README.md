# Edunova Consultancy 🎓

Engineering college admissions consulting platform
for post-inter students across AP, Telangana & more.

## About
Edunova helps students secure B.Tech seats based on
PCM percentage across top engineering colleges in
AP, Telangana, Tamil Nadu, and Bangalore.

## Features
- College recommendations based on PCM %
- Coverage: AP, Telangana, Tamil Nadu, Bangalore
- Student enquiry form with Google Sheets integration
- Google Analytics integrated
- Mobile responsive design

## Tech Stack
- GitHub Pages (hosting)
- Google Sheets API (enquiry form)
- Google Analytics
- Built using AI-assisted development (Claude AI)
